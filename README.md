# ROBO MODS STORE

A responsive storefront frontend built with Next.js, TypeScript and CSS.

## Features

- Dark black and navy design
- Customer and reseller portal screens
- Demo product catalogue and plans
- Responsive mobile and desktop layout
- Prepared for future backend API integration

## Important

This project is a frontend preview, not a production-ready store.

Login and signup are demo-only. No credentials are saved or verified.
Product names and prices are examples.

The following features still need backend integration:
- Real authentication
- Admin-managed products and prices
- Orders and order history
- Payment verification
- Reseller accounts and balances
- Secure inventory and digital delivery
- Database access policies

## Run locally

1. Install Node.js LTS.
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Deployment

Push the project to GitHub and import the repository into Vercel.

Configure environment variables in Vercel when the Supabase
integration is implemented.

Never commit real passwords or Supabase secret/service-role keys.
